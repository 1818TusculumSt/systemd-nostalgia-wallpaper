# Systemd Nostalgia

A cold blue, CRT-era Omarchy theme built around the `systemd_torvalds_1080p_16x9.mp4` wallpaper loop.

This theme uses a cyan-blue palette with a dark slate base so the desktop remains readable while the looping footage sits behind the panel and windows.

## Background

The live background is driven from Hyprland autostart with `mpvpaper`, using the 1080p wide video in `~/Downloads/systemd_torvalds_1080p_16x9.mp4`.

## Install

```bash
omarchy theme set systemd-nostalgia
```
